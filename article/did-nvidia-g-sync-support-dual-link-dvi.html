Did Nvidia G-Sync Support Dual-Link DVI?

Nvidia G-Sync has never operated over dual-link DVI ports. From its debut in 2013 to modern iterations, G-Sync has strictly required a DisplayPort connection (and later, select implementations over HDMI) to function. Dual-link DVI lacks the underlying communication protocols and packet-based architecture required to control panel refresh timings dynamically, meaning G-Sync was never engineered for or compatible with DVI interfaces.

The limitation stems from fundamental architectural differences between DVI and modern display interfaces. Dual-link DVI utilizes Transition-Minimized Differential Signaling (TMDS) to transmit continuous, raster-based video streams at fixed pixel clock rates. Because DVI is designed around rigid, fixed-timing standards, the GPU cannot arbitrarily delay the start of the next display frame without desynchronizing the link and causing the panel to lose its signal.

G-Sync relies entirely on manipulating the vertical blanking interval (VBI)—the pause between the end of one frame scan and the beginning of the next. To hold the display panel idle until the GPU finishes rendering a new frame, the interface must support dynamic packet transmission. DisplayPort natively accommodates this behavior through its micro-packet architecture, allowing the graphics card to dictate panel refresh cycles frame-by-frame. Dual-link DVI cannot accommodate this level of dynamic signaling.

This architectural requirement was evident with the very first commercial release of G-Sync. When Nvidia introduced the technology via a physical modification kit for the ASUS VG248QE monitor—a display that originally featured dual-link DVI, HDMI, and DisplayPort—the installation required technicians to remove the original internal scaler board entirely. The replacement G-Sync module board featured a single input: DisplayPort 1.2. The DVI and HDMI ports were completely discarded because the proprietary G-Sync FPGA module could only interface via DisplayPort.

While Nvidia eventually added support for variable refresh rates over HDMI via "G-Sync Compatible" mode (using HDMI 2.1 VRR) and updated native G-Sync modules to include HDMI inputs, dual-link DVI remained entirely obsolete in the variable refresh rate ecosystem. No adapter, driver modification, or hardware revision has ever enabled Nvidia G-Sync to function over a DVI connection.
