Single-Link DVI Maximum Data Rate Per Channel

In standard single-link Digital Visual Interface (DVI), the maximum data rate per channel is 1.65 Gigabits per second (Gbps). This article explains the technical specifications behind this throughput limit, how the underlying signaling standard calculates per-channel bandwidth, and how this relates to total display performance.

Standard single-link DVI relies on Transition-Minimized Differential Signaling (TMDS) to transmit uncompressed digital video data across three separate color channels (Red, Green, and Blue), alongside a fourth dedicated clock channel. Under the official DVI 1.0 specification, the maximum supported pixel clock frequency for a standard single-link connection is 165 MHz.

TMDS uses an 8b/10b encoding system, which converts every 8-bit byte of actual video data into a 10-bit symbol to minimize signal transitions and ensure DC balance. Because 10 bits are transmitted per clock cycle across each data line, the maximum bit rate for an individual data channel is calculated as:

165 MHz × 10 bits per cycle = 1.65 Gbps

With three active TMDS data channels running simultaneously at this rate, single-link DVI achieves a combined total bandwidth of 4.95 Gbps. After excluding the 8b/10b encoding overhead, the maximum raw pixel data throughput across all channels is 3.96 Gbps (or 165 megapixels per second).

This 1.65 Gbps per-channel limit standardizes single-link DVI to support maximum display resolutions of 1920×1200 (WUXGA) or 1920×1080 (Full HD) at a 60 Hz refresh rate using standard blanking intervals. Resolutions demanding higher throughput exceed the 1.65 Gbps per-channel threshold and require either reduced blanking timing or a dual-link DVI configuration, which adds a second set of TMDS data channels to double the overall capacity.
