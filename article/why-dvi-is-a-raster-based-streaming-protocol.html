Why DVI is a Raster-Based Streaming Protocol

The Digital Visual Interface (DVI) is classified as a raster-based streaming protocol because it transmits visual data as a continuous, uncompressed stream of individual pixels organized in horizontal lines from top to bottom, directly replicating the physical scanning pattern of a display. Unlike modern packet-based protocols that encapsulate video into addressable data packets, DVI continuously streams color and timing information in real-time using a fixed pixel clock.

The Raster Scanning Architecture

At its core, DVI was designed to replace analog VGA connections while maintaining backward compatibility with the behavior of Cathode Ray Tube (CRT) monitors and early LCD panels. CRTs generate an image via raster scanning—an electron beam sweeping horizontally across the screen, line by line, from the upper-left corner to the lower-right corner.

DVI digitizes this exact physical process:

  • Pixel-by-Pixel Transmission: Visual information is sent as a sequence of discrete color values (red, green, and blue) representing individual points on a grid.
  • Horizontal and Vertical Intervals: DVI maintains legacy raster timing, specifically horizontal blanking (HBLANK) and vertical blanking (VBLANK) intervals. In an analog CRT, these were periods where the beam turned off while repositioning to the next line or frame. In DVI, these intervals carry synchronization signals (HSync and VSync) rather than active pixel data, preserving the classic raster timeline.

Continuous Uncompressed Streaming

DVI is defined as a streaming protocol because of how it handles data over physical wires. It relies on Transition-Minimized Differential Signaling (TMDS), which converts parallel digital pixel data into high-speed serial streams.

  • No Packetization: Unlike modern interfaces such as DisplayPort, which bundle audio, video, and control data into discrete micro-packets with headers, DVI uses a continuous, dedicated data path. Every clock cycle on the dedicated clock channel directly corresponds to specific pixel data traveling across three parallel data channels.
  • Zero Overhead and Stateless Delivery: The transmitter does not retain memory of the frame, nor does it request retransmission if an error occurs. Once a pixel is transmitted, the connection immediately moves to the next pixel in the raster sequence.
  • Real-Time Display Update: The receiving device (monitor) directly decodes the incoming TMDS stream and writes the incoming pixel values directly to the display grid or panel driver without having to unpack or reassemble complex data frames.

Because DVI mimics the sequential line-by-line raster pattern and transmits an uninterrupted, clock-synchronized stream of uncompressed pixel values, it fits the technical definition of a raster-based streaming protocol.
